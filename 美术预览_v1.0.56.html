v1.0.56 战斗美术预览

绘制代码直接从 game - 副本.js 抽取，与游戏内表现一致。

1. 子弹外观（效果叠加）

每行左侧为该效果单独生效时的弹体，最后一行为全部叠加。子弹主体始终保持红色，避免与金币/经验球混淆。

2. 僵尸状态：冰冻 / 减速

冰冻 = 冰壳 + 棱线 + 边缘冰锥（完全停止移动）；减速 = 脚下紫色黏液 + 上浮气泡 + 身上薄雾。

3. 命中特效

循环播放：暴击（红环 + 金十字星）／冰冻（六角冰晶）／减速（紫色黏滞波纹）／不朽复活（紫色冲击波）。

4. 不朽之身：10 秒无敌护罩

紫色能量球 + 旋转六边形线框 + 顶点光点，头顶显示剩余秒数。
