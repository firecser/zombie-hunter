# 2026-10-20 · zombie-hunter 工作日志

## 真机反馈修复：自动射击完全不发射
- **用户现象**：① 点击技能图标没有子弹飞出去打怪；② 普通（无属性）子弹也不自动发射。
- **根因**：`ELEMENT_BULLET_SPEED = 640` 被当成**像素/秒**，但 `updateBullets()` 是 `bullet.x += bullet.vx` 的**像素/帧**模型（旧子弹 `player.bulletSpeed = 10`）。
  → 元素子弹一帧位移 640px，直接越过屏幕边界被 `splice` 回收，表现为「完全不发射」，且不报错。
- **修复**：`ELEMENT_BULLET_SPEED` 改为 **10（px/帧，≈600px/s）**，并加注释警告单位。
- **回归测试**：`smoke_p2.js` 新增第 7 项「子弹速度单位」——发射后调用一次 `updateBullets()`，断言子弹仍存活且单帧位移 1–30px（实测 10.0px）。这类「单位错但语法/数值测试全过」的 bug 以后能被抓住。
- **顺带说明**：点击坞图标是**切换元素**（不是释放技能），锁定元素点击无效；炮台按 220ms 自动射击。若用户希望「点击立即补一发」，需另加（当前未做）。
- **验证**：`node --check` OK；p1/p1_fix/p2/p3/p4/p5 六套冒烟全 PASS。
