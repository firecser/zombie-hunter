## Bug 修复：天赋页滚动变量未声明导致崩溃（runtime ReferenceError）
用户报：gamePage.html 控制台 `talentScrollY is not defined`（drawMainMenuTalent/gameLoop）、`talentDragStartY is not defined`（touchstart）。

### 根因
task #250 的滚动长列表改造里，`drawMainMenuTalent` 与触摸 handler 用了 `talentScrollY`/`talentDragStartY`/`talentDragStartScrollY` 三个变量，但只靠函数内的 `if(typeof x!=="number")x=0` 守卫赋值，**从未用 `var` 声明**。本游戏运行时对“未声明变量赋值/读取”按严格模式处理（隐式全局被禁），故守卫里的 `talentScrollY=0` 直接抛 ReferenceError；每帧 gameLoop 必崩。
- 验证手法：把 drawMainMenuTalent 丢进 `vm` 严格模式沙箱跑，先复现 `talentDragStartY is not defined`，确认根因。
- 排查澄清：`talentNodes` 报错是沙箱假象（真实 game.js 已 `var talentNodes` 声明）；`oS`/`roundRect` 同理是真实全局、沙箱未提供。真正缺声明的只有那 3 个滚动变量。

### 修复
在 game.js 顶部（与全文件其他全局一致的 `var` 声明区）前置声明：
`var talentScrollY=0,talentDragStartY=0,talentDragStartScrollY=0;`
- `talentNodes` 不动（本就声明过，去掉我误加的重复声明以避免 SyntaxError: Identifier 'talentNodes' has already been declared）。
- 已 `cp` 同步备份 `game - 副本.js`。

### 验证
- `node --check` game.js / 副本 均 PASS。
- 严格模式沙箱跑 drawMainMenuTalent：无抛错，talentNodes.length=71（全部命中框注册成功）；touch-start handler 跑天赋分支无 `talentDragStartY is not defined`。
