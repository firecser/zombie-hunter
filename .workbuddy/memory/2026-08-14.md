## v1.1.24 落地（战场左右透明边界 + 身体边缘钳制）
用户反馈：敌人被后坐力击退到屏幕边缘后无法被瞄准，却仍贴墙持续掉血。根因：`zombieShootable`(5422) 用中心点判定 `z.x<0||z.x>screenWidth` 返回 false；后坐力(4168) 沿子弹来向推 `zombie.x`，可把中心点推到屏幕外 → 不可瞄准但仍下落啄墙。

### 代码改动（game.js 改后 cp 副本；node --check SYNTAX_OK）
- 新增常量 `FIELD_X0=WALL_X0(0)` / `FIELD_X1=WALL_X1(screenWidth)`，与城墙两端对齐=屏幕左右缘。
- 新增 `clampZombieToField(z)`：以**身体边缘**为基准钳制 `z.x` 到 `[FIELD_X0+z.radius, FIELD_X1-z.radius]`，顶部 `z.y-z.radius<0` 也钳；极小屏兜底居中。
- 调用点两处：① `updateZombies` 每帧移动后（覆盖一切推动源，4195）；② 后坐力击退后立即（4168 块内，防止一帧越界）。
- 新增 `drawFieldBorders()`：左右缘向场内渐隐的半透明青色光带（仅视觉提示），在 playing/upgrade/gameOver 三处 `drawBackground()` 后调用。

### 效果
- 敌人身体边缘始终停在屏幕左右缘内 → 中心点恒在 `[radius, screenWidth-radius]` → `zombieShootable` 的 x 判定恒 true → 任何被击退的敌人都保持可被瞄准，且仍正常贴墙（不再有“隐形掉血”）。
