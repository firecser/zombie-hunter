## 油渍美术与火伤反馈对齐（v1.0.65，本地已 cp 同步，未推送）
- 用户反馈：油渍"实际效果和美术表现对不上"，要求对怪物产生伤害时怪物头上飘字，跟被子弹命中飘伤害数字的规则一样。
- 根因（无头测试 smoke_oil.js 验证）：油渍 DOT 在 updateZombies 已通过 `damageZombie(z, dot, false, '火')` 飘字，逻辑无 bug；但① 飘字是白色小字（dot=8%伤害且 <player.damage → 白色），淹没在玩家自动射击的白色子弹飘字中，反馈感极差；② 油渍美术是深棕色半透明小圆（`#3a2a10` alpha≤0.4），与"火灼烧伤害"语义完全不搭。
- **改动1 火伤飘字色**：`damageZombie` 飘字 color 新增 `element==='火' → '#ff7a1a'`（橙红），暴击仍红；火系（油渍DOT/爆炸火伤）统一橙红，明显区别于白色子弹字，仍走同一飘字规则。
- **改动2 油渍美术火焰化**：`drawFields` 油渍从棕色油洼改为「橙红燃烧火焰池」——`createRadialGradient` 橙黄→橙红→透明径向渐变 + `sin(Date.now()/110)` 呼吸脉动 + 中心 `quadraticCurveTo` 跳动火苗 + 外圈火光描边；按 `o.life/6000` 寿命淡出。微信小游戏 canvas 支持 createRadialGradient。
