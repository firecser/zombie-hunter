## 主游戏全面审查（GameDesigner 视角，核心战斗玩法）
- 审查结论：当前核心战斗是"坦克固定底部、自动瞄最近、自动射击、技能(油/雷/风)按CD全自动释放、撑满5分钟(victory)即胜"的**挂机生存计时器**。玩家在战场上零主动操作（仅升级三选一 + 点右下角炸弹按钮），违背"好玩=玩家决策"。
- 事实锚点：GAME_TIME_LIMIT=5min 固定生存计时；敌人 healthMult=(1+gameTime/50)*stage 线性膨胀(5min≈7x)；MAX_SKILLS=5 槽位+随机三选一(build不可控)；经济 sink 仅天赋购买(金币)，战斗内金币/经验只驱动随机升级；四支柱(异常交互/qualNodes/COMBO_DEFS/stunUntil)已实装但全自动释放使玩家无法主动触发。
- 最高优先优化：① 给玩家战场操作权（拖动坦克横移 + 手动选点放技能）；② 胜利条件从"撑时间"改"清波次/守核"；③ 技能手动释放使四支柱由玩家主动制造；④ 波次制替代固定计时重塑 session 节奏；⑤ 经济 sink 与 build 构建对齐。
- 本次仅审查出建议清单，未改代码。
