## 天赋升级弹窗 UI 优化（v1.1.49）

用户截图反馈弹窗有三个问题：
1. 标题显示 "root_wall"（英文 effect 键）而不是中文。
2. 升级按钮里金币与"升级"二字重叠。
3. 整体排版不够清晰。

### 根因
1. 大标题：弹窗顶部 `case b[13]` 渲染 `T["icon"]`（= effect 键），`case 1` 渲染 `"效果: "+T["effect"]`，中文名 `T["name"]` 反而在中间位置（`case b[10]`），视觉层级错乱。
2. 按钮重叠：`case b[49]` 把 `fU+T["cost"]` 画在按钮内部 `Q+X-8`（按钮底部），与 `drawRoyaleBevelButton` 自带的"升级"标签中心位置撞在一起。

### 修复
1. `case b[13]`：`T[d[2]]`（icon 键）→ `T[F]`（name，中文），顶部大标题变成节点中文名。
2. `case 1`（副标题）：用 effect 键前缀映射成中文分类——
   - root_* → 根脉
   - coeff_* → 属性加成
   - elem_def_* → 元素防御
   - elem_hp_* → 元素生命
   - elem_crit_* → 元素暴击
   - unlock_* → 解锁门
   - syn_* → 协同
   不再显示生硬的 "root_wall"。
3. `case b[49]` 可升级分支：把"🪙 40"从按钮内部 `Q+X-8` 移到按钮上方 `Q-18`，加"需要"前缀 + 金色 `e[0]=#ffd700`，按钮里只剩干净的"升级"。

### 验证
- `node --check` 双文件 PASS；`backup` 与 `game.js` 等长（666123），3 处修改一致。
- Node 模拟分类：root_wall→根脉 / coeff_火→属性加成 / elem_def_火→元素防御 / 全部 effect 类型映射正确。
- 提交 + tag **v1.1.49**（不推送）。
