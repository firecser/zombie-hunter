## 激励视频广告：暂停 + 每关上限
- 需求：① 播放广告时游戏暂停；② 每关看广告补炸弹次数上限 3 次。
- 新增全局 `adWatchCount`（`startGame` 重置为 0）+ 常量 `AD_WATCH_MAX_PER_LEVEL=3`。
- `showRewardedAd`：调用时若正在游玩且未手动暂停，则 `gamePaused=true`（pausedByAd 标记）；`ad.onClose` 回调里无论如何 `resume()` 恢复，`gamePaused=false`。失败重试链 catch 也 resume。不覆盖手动暂停。
- `grantAdBombAndRelease`：发放前双重校验 `adWatchCount >= AD_WATCH_MAX_PER_LEVEL` 直接 return；达标才 `adWatchCount++` 并补弹释放。
- 炸弹按钮点击守卫（onTouchStart 无弹/冷却分支）：达上限弹 `wx.showToast('本关观看次数已用完')`，不再拉起广告。
- 验证：node --check 双文件 OK；无头逻辑测试 12 项全过（广告弹出/暂停/恢复、3 次计数+释放、上限 toast、未看完不发放不计数、未看完仍恢复）。

## 修复：看广告后背景音乐消失
- 原因：BGM 用 `wx.createWebAudioContext()`；微信播放激励视频会把 AudioContext 挂起（suspended），广告关闭后 context 不自动恢复，导致音乐永久静音。
- 修复：`showRewardedAd` 的 `resume()` 回调里，广告结束后调用 `AudioSystem.resume()`，并在 `gameRunning && musicEnabled && ctx.state==='running'` 时 `AudioSystem.startBGM()` 重启 BGM（startBGM 内部先 stop 旧的再起新的）。
- 验证：无头测试 5 项全过（模拟 context 被挂起 → 广告结束恢复 running + BGM 重启；音乐关闭时只恢复 context 不重启 BGM）。双文件 node --check OK。

## 修复：看广告后过一会游戏卡死（drawMine 颜色拼错）
- 现象：3 次广告看完过一会，游戏帧崩溃卡死。报错 `addColorStop ... 'rgba(255,0.95)' could not be parsed`，来自 `drawMine`（game.js:2238）。
- 根因：`drawMine` 发光核心颜色基串 `coreBase = armed ? 'rgba(255,' : 'rgba(120,175,255,'`，armed 分支漏了 G/B 通道；拼出 `${coreBase}0.95)` = `rgba(255,0.95)` 非法，CanvasGradient.addColorStop 抛异常打断 gameLoop → 卡死。触发时机：地雷布署且 `now >= m.armTime`（armed=true）后才走该分支，所以"布雷→看完广告→雷激活"瞬间才崩。
- 修复：`coreBase` armed 分支改为 `'rgba(255,90,60,'`（红心），armed 时拼出 `rgba(255,90,60,0.95)` 合法。副本与 game.js 同步，node --check 双文件 OK。
- 附带说明：日志里的 `insertTextView/updateTextView ... 33642 not found` 是激励视频广告原生组件（关闭按钮等）的清理告警，来自微信广告 SDK 而非 canvas 代码，非致命、不影响游戏主循环，无需改动。

## 火力强化分支树重平衡 + 基础卡可刷出
- 现象：① 刷出分支后基础"火力强化"伤害卡不再出现；② 各分支强度严重失衡（蓄能 24× vs 狂暴 1.35×，差 18 倍）。
- 数值模型（已理清）：每次选火力强化(基础或分支) `player.damage *= 1.12`（全局因子 1.12^L，L=该大类总选次数）；分支倍率 `dmgMul/fireMul`（offensive 路径 DPS 比较只看这个，全局 1.12^L 各路径共有）。
- 修复①（基础卡可刷出）：`showUpgradePanel` 三选一由 `sort().slice(0,3)` 改为 `weightedPick3(cards)` 加权抽取；`upgradeCardWeight`：火力强化基础卡 2.0、分支卡 1.0、其余 1.4。基础与分支不互斥，加权后基础卡刷出率 43%→65%（无头统计 5000 次）。
- 修复②（平衡）：三条进攻分支每级用复合乘法因子，收敛到同一 DPS 曲线 ≈1+0.25*bl。最终系数：
  - 重型枪管 dm1.15/fm(1/1.03)/rm1.20；狂暴连射 dm0.96/fm0.82；蓄能 dm1.35/fm1.147；穿甲 armor+0.30/级(对坦克/Boss)；后坐力 knockF=15/级；校准 hitbox1.18/级。
  - bl=5 时：重型2.33×/狂暴2.20×/蓄能2.26×(差<6%)；穿甲对Boss×2.5；L20纯路径总倍率22.5/21.2/21.8，基本一致。
  - 平衡穷举脚本 `_fh_balance.js`；逻辑测试 `_fh_test.js`（36 项全过，含加权刷出率断言）。
- 已同步 game.js，node --check 双文件 OK。
