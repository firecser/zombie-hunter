# 微信小游戏提审清单

## 1️⃣ 微信公众平台操作（你先做）

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 你的小游戏

### □ 隐私政策（重要！现在必过）
- 进入「设置 → 基本设置 → 服务声明 → 更新」
- 可以选「生成模板」快速创建，或者自己写
- 不用太复杂，说明收集了哪些信息（微信昵称、头像）、怎么用就行

### □ 游戏类目选择
- 选择「**休闲游戏**」或「**动作闯关**」
- 选错了会导致审核不通过

### □ 准备提审素材
| 素材 | 要求 | 建议 |
|------|------|------|
| 游戏 icon | 108×108px，≤ 120KB | 用你的骷髅怪角色 |
| 截图（至少1张，建议4张） | 1080×1920，≤ 1MB/张 | 主界面、战斗界面、天赋界面、排行界面各一张 |
| 游戏描述 | 100字以内 | 写清楚核心玩法 |
| 游戏标签 | 选1-3个 | 如：塔防、动作、休闲 |

### □ 基础设置检查
- 确认 AppID 正确（当前：`wx82946280a9b98e78`）✅
- 确认代码包中的 game.json 已配置 ✅

## 3️⃣ 提审操作步骤

### 步骤1：微信开发者工具打开项目
```
微信开发者工具 → 导入项目 → 选择你的 zombie-hunter-game 文件夹
```

### 步骤2：上传代码
```
开发者工具 → 工具栏 → 上传 → 
  版本号：1.0.15（或当前最新）
  备注：第一次提审
```

### 步骤3：在mp后台提交审核
```
登录 mp.weixin.qq.com → 版本管理 → 开发版本 → 提交审核
  - 填写版本描述
  - 选择类目
  - 上传截图和icon
  - 提交
```

### 步骤4：等待审核（通常1-7天）
- 审核通过 → 点击发布 → 游戏上线
- 审核被拒 → 查看驳回原因 → 修复后重新提交
