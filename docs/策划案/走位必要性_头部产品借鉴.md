# 走位必要性：头部产品怎么做的 & 五个可选方案

| 项 | 内容 |
|---|---|
| 现状 | 走位只能"多接几个球"，**不动也能通关** → 不是刚需 |
| 结论 | 走位要成为刚需，必须满足其一：**移动有代价**（不动更亏）或**不动有威胁**（不动会死） |
| 日期 | 2026-10-21 |

---

## 一、头部产品是怎么让走位变成刚需的

| 产品 | 走位的作用 | 机制本质 | 能否借鉴 |
|---|---|---|---|
| **《弓箭传说》Archero** | **站定才自动射击，移动时停火** | **移动 = 放弃输出**，形成"打还是躲"的取舍 | ⭐⭐⭐⭐⭐ 最直接 |
| **《向僵尸开炮》** | 躲弹幕/爆炸、捡经验 | 不动的威胁来自"敌方投射物" | ⭐⭐⭐⭐ 需加投掷怪 |
| **《吸血鬼幸存者》** | 走位是唯一操作，边跑边打 | 接触伤害 + 拾取宝石 | ⭐⭐⭐ 需接触伤害 |
| **《土豆兄弟》** | 躲精英冲锋、捡材料 | 敌方冲锋锁定玩家 | ⭐⭐⭐⭐ |
| **《弹壳特攻队》** | 躲弹幕 | 弹幕密度极高 | ⭐⭐ 我们要加弹幕系统 |
| **《元气骑士》** | 手动瞄准 + 走位 | 操作即输出 | ⭐ 与自动射击冲突 |

### 提炼出的三条法则

1. **移动必须"有机会成本"**——Archero 的停火是最干净的实现。
2. **威胁必须"锁定玩家"**——怪打城墙，走位就没意义；怪打你，走位才有意义。
3. **收益要"位置相关"**——同样的奖励，站对地方才拿得到。

> 我们目前三条**一条都不满足**：移动不停火、怪物只打墙、奖励满地图掉。

---

## 二、五个可选方案

### 方案 A · 移动停火（Archero 式）⭐ 最直接

| 项 | 设计 |
|---|---|
| 规则 | 拖动移动时，炮台**停止自动射击**；松手 0.15s 后恢复 |
| 体验 | "我要不要为了这颗球放弃 1 秒输出？"——每 5 秒一次真实取舍 |
| 改动 | **~10 行**（`isMoving` 标记 + 更新循环判断） |
| 风险 | 玩家可能"不敢动"→ 走位反而更少；需要配合"轻点移动"（短距离微调不停火） |
| 适配 | 与五行/词条完全正交 |

### 方案 B · 移动降射速（柔和版）⭐ 推荐先试

| 项 | 设计 |
|---|---|
| 规则 | 移动时射速 ×0.5（600ms → 1200ms），松手立刻恢复 |
| 体验 | 保留"取舍"，但不至于完全停火，容错更高 |
| 改动 | **~8 行** |
| 风险 | 感知可能不够强，需要 HUD 提示"移动中·射速↓" |

### 方案 C · 投掷怪 / 冲刺怪（威胁锁定玩家）

| 项 | 设计 |
|---|---|
| 投掷怪 | 每 6–8 秒出现，举臂 0.8s 预警，向**玩家当前位置**抛掷落点（半径 45），命中扣城墙血或眩晕 0.5s |
| 冲刺怪 | 血量 50% 时锁定玩家 x，0.7s 预警后直线冲刺，撞到则击退 + 眩晕 0.6s |
| 体验 | 不移动 = 挨打，**走位变成保命** |
| 改动 | **~200–260 行**（敌方投射物 + 预警 + 命中判定） |
| 风险 | 叠加"读色 + 点坞 + 接球"后，操作线程过多（之前评估过） |

### 方案 D · 元素灵脉（站位收益）

| 项 | 设计 |
|---|---|
| 规则 | 场上随机生成「灵脉」（半径 50 的光圈，存在 6s），站进去：元素印 +1/秒、连杀不断 |
| 体验 | "那边有个灵脉，我过去站一会儿"——**移动有明确正收益** |
| 改动 | **~90 行**（区域生成 + 判定 + 视觉） |
| 风险 | 收益偏隐性，需要强视觉（光圈 + 充能音） |

### 方案 E · 城墙分段（移动=救火）

| 项 | 设计 |
|---|---|
| 规则 | 城墙分 3 段，各段独立血量；怪攻击落点所在段，玩家移动到该段可"抢修" |
| 体验 | 三线救火，张力强 |
| 改动 | **~300 行 + 关卡重做** |
| 风险 | 与现有"单血条"表现冲突，UI 要重做 |

## 三、对比

| 方案 | 走位刚需度 | 改动量 | 认知负担 | 与五行兼容 |
|---|---|---|---|---|
| A 移动停火 | ★★★★ | 极小 | 低 | ✅ |
| **B 移动降射速** | ★★★ | 极小 | 低 | ✅ |
| C 投掷/冲刺怪 | ★★★★★ | 中 | **高** | ✅ |
| D 元素灵脉 | ★★★ | 小 | 低 | ✅（强化积印） |
| E 城墙分段 | ★★★★ | 大 | 中 | ✅ |

---

## 四、推荐：**B + D 组合**（先做），C 作为下一阶段

- **B** 给"移动"一个代价（射速减半），解决"不动更赚"的问题
- **D** 给"移动"一个理由（灵脉充能），避免"能不动就不动"
- 两者一推一拉，形成**位置决策**，且不增加"躲弹幕"的高压操作

预估 **≈100 行**，一天内可验证。

如果 B+D 之后仍觉得"没必要动"，再上 **C（投掷怪）**——那是真正的"不动会死"，但也最考验操作负荷。

## 六、已实施（2026-10-21）：B + D，C 留待下一阶段

### B · 移动降射速

| 项 | 实现 |
|---|---|
| 判定 | `onTouchMove` 在战场区域移动时 `moveUntil = now + 150ms` |
| 生效 | `update()` 中 `_fireGap = ELEMENT_AUTO_FIRE_RATE × (moving ? 2 : 1)` → **600ms**（原 220ms 的半速） |
| 提示 | 坞上方显示「移动中 · 射速 ↓」 |

### D · 元素灵脉

| 项 | 实现 |
|---|---|
| 生成 | 每 **9s** 刷 1 个（同屏上限 2），位置随机 x∈[70, 屏宽-70]，y = 屏高 52% |
| 存续 | **6s**，外圈有收缩环显示剩余时间 |
| 收益 | 站进半径 **52** 内：每 **1s** 当前元素 +1 印，并**续连杀窗口** |
| 视觉 | 元素色光圈 + 中心「灵」字 + 上浮粒子 |

### 验证

```
node --check → SYNTAX_OK
smoke_p9    → 10 项 PASS（新增 B 接线 / D 灵脉内外判定与生成）
p1~p5 + p7 + p8 → 全部 PASS
```
