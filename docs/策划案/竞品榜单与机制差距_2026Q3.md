## 二、把《向僵尸开炮》拆开看

它能连续多月第一，不是因为"僵尸"题材，而是这套循环：

| # | 机制 | 具体做法 | 玩家获得的感受 |
|---|---|---|---|
| 1 | **走位** | 拖动角色在底部左右/上下移动，自动射击 | 有操作、能躲、能被追 |
| 2 | **弹幕成长** | 升级后子弹数量/形态肉眼可见变多 | "我变强了" |
| 3 | **技能进化** | 三选一里的词条可**合成超武**（冰霜+连发=冰锥散射） | 构筑感、每局不一样 |
| 4 | **质变节点** | 某些等级直接换形态（激光、爆炸） | 期待感 |
| 5 | **大数字** | 暴击、连击数字刷屏 | 数值暴力 |
| 6 | **短关卡** | 3–5 分钟一局，波次紧凑 | 碎片时间友好 |
| 7 | **经验拾取** | 要走过去吃经验球 | 走位有收益 |
| 8 | **局外长线** | 装备、伙伴、皮肤、天赋 | 留存 |

## 三、我们的差距（逐项对照）

| 机制 | 向僵尸开炮 | 本作 v2.4 | 差距 |
|---|---|---|---|
| 空间操作 | 拖动走位、躲弹幕、吃经验 | **站桩固定炮台** | 🔴 **完全没有** |
| 弹幕规模 | 后期满屏 | 单发（点击补射 1 发） | 🔴 差一个量级 |
| 技能进化 | 词条可合成超武 | 只有数值卡（+15% 隐形） | 🔴 **没有构筑** |
| 质变节点 | 有 | 无（40 个节点全是数值） | 🔴 |
| 大数字 | 暴击刷屏 | 34px 暴击，量级仍小 | 🟡 |
| 关卡节奏 | 3–5 分钟 | ✅ 5.4 分钟 | 🟢 |
| 题材差异 | 末日僵尸 | ✅ 冰雪僵尸 + 汉字五行 | 🟢 **有辨识度** |
| 局外长线 | 装备/伙伴 | ✅ 5 元素树 | 🟢 |
| 相生/克制 | 无 | ✅ **独有** | 🟢 **差异化资产** |

> **诊断**：我们有一个**别人没有的规则（五行相生相克）**，但把它做成了"判断题"；
> 而榜首产品有**空间操作 + 构筑进化**这两个"动词"，玩家一直在动、一直在变强。

## 四、三套机制改造（不是加特效，是加动词）

### M1 · 走位（空间维度）⭐⭐⭐ 最能解决"不够玩"

| 项 | 设计 |
|---|---|
| 操作 | **拖动屏幕任意位置 → 角色左右移动**（限制在城墙前一条带上）；点击坞仍是切元素/补射 |
| 收益 | 走位躲「自爆怪」「远程投掷」；走过经验球自动拾取 |
| 代价 | 需要新增 2 类怪物行为；失败条件从"城墙"变成"角色 + 城墙" |
| 风险 | 要重做关卡节奏与数值（P6 全部作废） |
| 改动量 | **大**（约 600 行 + 关卡重校） |

### M2 · 技能进化（构筑维度）⭐⭐⭐ 最接近榜首、风险最低

| 项 | 设计 |
|---|---|
| 词条化 | 三选一从"元素精通/连携/克制/通用"改为**词条**：连发、穿透、爆炸、冰缓、燃烧、弹射 |
| 合成 | 同词条 **3 级 → 进化成超武**：<br>连发Ⅲ + 火 = **火焰喷射**<br>穿透Ⅲ + 金 = **穿甲激光**<br>弹射Ⅲ + 木 = **藤蔓领域**<br>冰缓Ⅲ + 水 = **冰环**<br>燃烧Ⅲ + 土 = **熔岩地带** |
| 质变 | 进化后子弹**换形态**（颜色、体积、音效全变） |
| 与五行的关系 | 词条决定"怎么打"，五行决定"打谁"——两个维度正交，不打架 |
| 改动量 | **中**（约 350 行；不需要重做关卡） |

### M3 · 弹幕成长（视觉维度）⭐⭐ 跟随 M2 自然产生

- 元素精通/连杀层数 → **弹道数 1 → 3 → 5**（扇形散开）
- 成本最低，爽感立竿见影，但单独做容易变成"纯视觉"

---

## 五、建议路径

| 阶段 | 内容 | 理由 |
|---|---|---|
| **先做 M2** | 技能进化（词条 + 3 级合成超武） | 改动集中、不动关卡、直接补上"构筑"这个最大缺口 |
| **再做 M3** | 弹道数随精通/连杀成长 | 跟随 M2，几乎零额外成本 |
| **最后评估 M1** | 走位 | 结构性最强，但要重做关卡与数值，放在有留存数据之后 |

> 如果目标是**买量素材**（抖音前 3 秒），M3 必须做——满屏弹幕是短视频里最抓眼的一帧。

---

## 六、风险与红线

1. **不能把五行做丢**：词条是"怎么打"，五行是"打谁"，两者必须正交
2. **不要一次上三个**：M2 → M3 → M1，每步真机验证
3. **微信/抖音两套素材**：微信讲"五行流派"，抖音讲"满屏清怪"
