# 「接掉落物」三条改动的客观评估

| 项 | 内容 |
|---|---|
| 用户提案 | ① 磁吸半径再砍半（110→55）② 金币也竖直下落（含后续掉落物）③ 落地不停、直接漏过去 |
| 结论 | **方向正确，但按原案实现会形成"负反馈死亡螺旋"，与 18–30 休闲人群的耐心不匹配。建议采用修正案（保留紧张感、去掉惩罚感）** |

---

## 一、先说结论

| 提案 | 是否符合目标人群 | 风险 |
|---|---|---|
| ① 半径砍半到 55 | **部分符合**：走位意义变强 ✅，但 55px 已接近"像素级对准" | 中 |
| ② 金币也下落 | **符合**：统一掉落物规则，认知成本低 | 低（但需保证金币不会大量漏掉） |
| ③ 落地直接漏过 | **不符合原样**：会打断"每波升 1 级"的节奏契约，形成死亡螺旋 | **高** |

---

## 二、逐条分析

### ① 磁吸 110 → 55：能让走位有意义，但开始要求"对准"

- 屏宽 390，玩家可移动范围 44–346。
- **110px ≈ 屏宽 28%**：大致"站在这半边就能吸到"。
- **55px ≈ 屏宽 14%**：必须基本站在球的正下方。

**问题不在"追不上"**（拖动是手指直接定位，没有速度上限），
**问题在注意力分配**：玩家同时要做四件事——

1. 看怪物颜色（决定点哪个元素）
2. 点底部五行坞（手指在屏幕下沿）
3. 左右拖动接球（同一根拇指）
4. 看连杀/印数（顶部与图标角标）

> 18–30 岁休闲玩家的单局耐心约 3–8 分钟，**同时处理 4 条线程时，最先被放弃的一定是"接球"**。
> 结果不是"更投入"，而是"算了，不接了"。

### ② 金币也下落：符合，但必须防止经济漏损

- 统一规则（所有掉落物都下落）**降低认知成本**，符合直觉。
- 但金币是**局外成长的唯一硬通货**（P6b 刚把 60 关收入调到覆盖满树 87.8%）。
- 若金币也会漏掉 30–50%，等于把经济覆盖从 87.8% 打到 50% 左右 → **养成明显变慢**，留存受损。

> 建议：金币可以下落，但**落到城墙线自动收取**（不消失）；只有经验球会漏。
> 这样"追金币"是加速，"漏金币"不会惩罚。

### ③ 落地直接漏过：风险最高，会引发死亡螺旋

这是三条里唯一会**改变游戏数学结构**的一条。

**（a）反应时间不够**

当前下坠速度 3.2px/帧 ≈ 192px/s。怪死在 y≈350–500，城墙线 y≈557：

| 死亡位置 | 落到墙线耗时 |
|---|---|
| y=500 | **0.3 秒** |
| y=400 | **0.8 秒** |
| y=300 | **1.3 秒** |

人类"看到→判断→移动手指"约需 **0.4–0.6 秒**，且同时有多个球时还要选目标。
**0.3–1.3 秒的窗口在体感上等于"来不及"**，不是"紧张"。

**（b）经验契约会被打破**

`EXP_BASE` 是按「每波清完 = 升 1 级 = 一次三选一」设计的。
若漏掉 40% 经验球，升级速度变成 0.6×/波 → 词条更少 → 输出更低 → 清怪更慢 → 球更少 → **越玩越弱**。

这是典型的**负反馈螺旋**（rich get richer 的反面），
休闲玩家对它的描述是"这游戏在针对我"，而不是"我技术不行"。

**（c）视觉与物理不自然**

城墙在 y≈557，坞在更下方。掉落物"穿过城墙掉进技能坞"在画面上很怪，
除非专门做"掉进城墙缝隙"的表现。

## 三、目标人群视角（18–30 岁 / 微信小游戏）

| 特征 | 对提案的含义 |
|---|---|
| 碎片时间 3–8 分钟 | 能接受"每 10–20 秒一次小紧张"，**不能接受持续紧张** |
| 单手竖屏 | 拖动 + 点坞是同一根拇指，**双动作冲突** |
| 损失厌恶强 | 掉落消失 = 损失；连续漏 3 个就会烦躁 |
| 喜欢"捡东西"的爽感 | ✅ 追着捡本身是正反馈，**但前提是"基本都能捡到"** |
| 抖音买量素材 | 满屏掉落 + 追着捡**很好看**，但实机留存看的是"漏了会不会崩" |

> 一句话：**"必须去接"是对的，"接不到就没了"是错的。**

## 四、修正案（推荐）

保留提案的全部意图，只改三个参数 + 一个兜底：

| 项 | 原案 | 修正案 A（推荐） |
|---|---|---|
| 磁吸半径 | 55 | **70**（≈屏宽 18%，需大致站在下方，但不要求像素级） |
| 身体拾取判定 | 未定 | **玩家半径 22 + 球半径 6 ≈ 28px**，贴身必吃 |
| 金币 | 下落 + 会漏 | **下落，但落到墙线自动收取**（不漏） |
| 经验球 | 下落 + 漏过消失 | **下落 + 漏过消失，但漏掉返还 50% 经验** |
| 下坠速度 | 3.2px/帧 | **1.4px/帧**（≈84px/s，从 y=400 到墙线约 **1.9s**，可反应） |
| 消失预警 | 无 | 最后 **0.6s 闪烁 + 缩小**，明确"要没了" |
| 经验契约 | 破坏 | **保底返还**让"每波≈1 级"仍成立，只是接得准会略快 |

### 为什么 50% 返还很关键

- 接满：100% 经验，升级略快
- 全漏：仍有 50%，**节奏不会崩**，只是少了奖励
- 玩家感受从"我亏了"变成"我没拿到全额"——**同样是损失，但不会影响生存**

## 五、备选：硬核案 B（如果你要更强的紧张感）

| 项 | 参数 |
|---|---|
| 磁吸 | 55 |
| 经验球 | 漏过消失、**不返还** |
| 金币 | 漏过消失 |
| 补偿 | 每漏 10 个，城墙回 5% 血（"回收残缺能量"） |

- 适合：核心向、愿意重复挑战的玩家
- 不适合：微信小游戏首周留存；抖音买量进来的泛用户大概率 3 分钟内流失

---

## 六、建议

1. **采纳 ①（半径缩小）+ ②（金币下落）**，但半径定 **70** 而非 55
2. **③ 改为"经验球会漏 + 50% 返还 + 下坠放慢到 1.4 + 消失预警"**
3. **金币到墙线自动收取**，保护已调好的经济
4. 上线后看两个指标：**平均每局拾取率**（目标 60–75%）与**每波升级是否仍为 1 级**

> 如果实测拾取率 <50%，说明半径或下坠速度还要放宽；>85% 则说明紧张感不足，可以再收。

## 七、已实施（2026-10-21，用户选 A 案）

| 项 | 落地参数 |
|---|---|
| 磁吸半径 | `ORB_MAGNET_R = 70`（≈屏宽 18%） |
| 下坠速度 | `ORB_FALL_SPEED = 1.4 px/帧` ≈ 84px/s（y=400 → 墙线约 1.9s） |
| 经验球 | 竖直下落；贴身/磁吸拾取；**漏过墙线消失并返还 50% 经验** |
| 金币 | **同样竖直下落**；墙线附近（`WALL_Y-12`）**自动收取**，不漏 |
| 预警 | 经验球进入墙线前 60px 开始**闪烁** |
| 未来掉落物 | 统一按「竖直下落 + 磁吸 + 墙线处理」处理 |

### 实现位置

- `updateOrbs()`：两个循环均为「先下落 → 磁吸 → 贴身拾取 → 墙线结算」
- `drawOrbs()`：经验球 `_danger` 闪烁

### 验证

```
node --check → SYNTAX_OK
smoke_p9    → 8 项 PASS（新增：统一下落 / 半径70 / 漏球返50% / 金币自动收）
p1~p5 + p7 + p8 → 全部 PASS
```

> 上线后建议观察两个指标：**每局拾取率**（目标 60–75%）与**每波升级数**（应仍≈1）。
