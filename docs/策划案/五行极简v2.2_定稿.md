## 1. 背景与目标

**问题**：旧技能体系（15 个技能 + 每个技能一棵属性分支树 + 18 种局外天赋树共 119 节点）对玩家认知负荷过高，学习成本远超休闲用户的耐心。

**目标人群**：国内 18–49 岁、以男性为主的休闲小游戏玩家；注意力短、不愿读长文本、习惯「看图即懂」。

**设计原则**：

1. **唯一战略内核 = 五行相生相克**，其余系统一律砍到最薄。
2. **零文本学习**：怪物与技能全部用「汉字 + 颜色」双重编码，色弱也能靠字形区分。
3. **渐进暴露**：开局只给 2 个元素、不展示相生；全 5 元素在第 4 关（约 20 分钟）内开完。
4. **读色选克 = 核心操作快感**：选对克制 ×2.5，选错（同元素）×0.2，形成 12.5 倍落差。

---

## 2. 核心循环（三层）

| 层级 | 周期 | 内容 | 玩家动作 |
|---|---|---|---|
| **秒级** | 1–3 秒 | 读色选克：看场上怪物汉字颜色 → 点底部对应克制元素图标 | 点击坞图标切换元素 |
| **分钟级** | 30–60 秒 | 局内元素精通：三选一提升某元素等级 / 相生连携 / 克制增幅 | 三选一选卡 |
| **长期** | 数小时 | 局外 5 元素树养成（每棵 ~8 节点），提升元素基础 DPS 与解锁高阶卡 | 花金币点天赋 |

**Fun Hypothesis**：玩家在「颜色识别 → 切换元素 → 伤害数字暴涨」的即时反馈中获得掌控感；相生连携提供第二次「原来还能这样」的发现快感。

## 3. 五行规则（唯一战略内核）

### 3.1 相克（怪 → 克制它的玩家元素）

| 怪物元素 | 克制它的玩家元素 | 效果 |
|---|---|---|
| 金 | **火** | ×2.5 |
| 木 | **金** | ×2.5 |
| 水 | **土** | ×2.5 |
| 火 | **水** | ×2.5 |
| 土 | **木** | ×2.5 |
| （同元素） | 同元素自身 | **×0.2（错配惩罚）** |
| 其余 | 非克制非相同 | ×1.0（中性） |

代码常量：`ELEMENT_COUNTER = { '金':'火', '木':'金', '土':'木', '水':'土', '火':'水' }`

### 3.2 相生（连携）

`水生木 / 木生火 / 火生土 / 土生金 / 金生水`

- **触发**：玩家把当前元素切换到「被上一个元素所生」的元素（例：上一个用水，现在切木 → 水生木）。
- **效果**：4 秒内全伤害 +20%，坞上叠加**青色脉冲环 + 「连携」标**（与相克红色脉冲同一视觉层级，明显可见）。
- **暴露节奏**：L1–L12 不教学相生；**L13–L18 首次教学连携**（此前玩家已熟练掌握相克）。

### 3.3 双系相生怪

部分关卡怪物带两个元素（`zombie.elements`）。伤害倍率取**各系最差克制的最小值**，防止单属性同时碾压两系——必须靠对应相生配对或高火力才能突破。

## 4. 关卡与元素节奏（60 关 = 10 章 × 6 关，每关 ≈5.4 分钟）

**第 1 章（1–6 关）= 五行教学章**：怪物元素按**波次**投放（`buildTeachingWaveElements`），
且保证「该怪的克制元素本关必已解锁」。

| 关卡 | 开放元素 | 本关怪物元素（逐波） | 教学目的 |
|---|---|---|---|
| **L1** | 火、水 | 前 10 波 **金**（火克）→ 后 10 波 **火**（水克） | **一关之内**教会「读色换元素」 |
| L2 | + 木 | 金 / 火 / **土**（木克） | 引入第三元素 |
| L3 | + 土 | 金 / 火 / 土 / **水**（土克） | 引入第四元素 |
| L4–6 | 全 5 | 金 / 火 / 土 / 水 / **木**（金克） | 五行完整 |
| L7–12 | 全 5 | 章节元素（水→木→火→金→土） | 巩固单向克制 |
| **L13–18** | 全 5 | 双系相生 | **相生连携教学**（首次触发弹横幅） |
| L19–60 | 全 5 | 双系相生 | 扩展与高难 |

> **不变量**（`smoke_p5.js` 全 60 关逐波守护）：每只怪的克制元素必须已在该关解锁。
> 若未来改关卡数据破坏此条，测试立刻 FAIL。

## 5. 战斗数值基线（已由 `scripts/sim_v22_real.js` 按**真实出怪表**校准）

### 5.1 锁定常数

| 常量 | 值 | 说明 |
|---|---|---|
| `ELEMENT_AUTO_DPS` | **40** | 固定炮台中性保底 DPS |
| `ELEMENT_BASE_DPS` | 金 **300** / 火 **240** / 木 **180** / 土 **170** / 水 **170** | 五元素基础 DPS（Lv1）。水/土原为 90/120，P6 调平——v2.2 已删控制/护盾，不再为职能买单 |
| `ELEMENT_AOE` | 金 **1.4** / 火 **1.6** / 木水土 **1.0** | 多目标等效（仅克制时生效） |
| 克制倍率 K | **2.5**（克制，可被「克制增幅」卡升至 3.5）/ **0.2**（同元素）/ **1.0**（中性） | `getElementBonus` |
| `LvMul` | **1.15^(lv−1)**，Lv10 封顶 | 元素熟练度成长（局内精通 + 局外树起始等级） |
| 炮台射速 | **220 ms**（≈4.55 发/s） | 固定，不受旧「火力强化」影响 |
| 连携增益 | ×**1.20**，持续 **4s** | 相生触发，可被「相生连携」卡提升至 1.6× / 8s |

### 5.1b 出怪与血量常数（P6 方案 A 定标）

### 5.2 伤害公式

```
单发基础伤害 = (ELEMENT_AUTO_DPS + ELEMENT_BASE_DPS[el] × LvMul(el)) / 射速Hz
命中实际伤害 = 单发基础 × getElementBonus(zombie, el) × (克制 ? ELEMENT_AOE[el] : 1.0)
```

等价于模拟器的 `DPS = (autoDPS + E_BASE×LvMul×K) × AOE`。

### 5.3 校准结论（真实出怪表 + 真实体型血，墙血 2000）

| 关卡 | 错配（用错元素） | 克制 · 零养成 | 克制 · 养成 |
|---|---|---|---|
| L1 教学 | 崩 181s | **WIN（余 1058）** | WIN |
| L4 全 5 开 | 崩 175s | **WIN（余 1311）** | WIN |
| L13 相生 | 崩 165s | **WIN（余 1978）** | WIN |
| L30 中期 | 崩 155s | **WIN（余 1600）** | WIN |
| L55 后期 | 崩 161s | **WIN（余 1150）** | WIN |

**形态**：读错色 → 必崩（143–181s）；读对色 → 零养成可过前中期；**终章必须局外养成**；养成后满血清。

## 6. 美术：国风化桥接

### 6.1 汉字怪物（参考《赵云与阿斗》）

- **主体 = 大号书法汉字**「金 / 木 / 水 / 火 / 土」，元素色填充 + 暗色描边，形成印章质感。
- **类型区分**（不靠文字，靠视觉）：

| 类型 | 字号系数 | 描边 | 附加 |
|---|---|---|---|
| 普通 | 1.5 | 3 | — |
| 快速 | 1.35 | 2 | 偏小、移动快 |
| 坦克 | 1.9 | 5 | 粗描边 |
| BOSS | 2.5 | 6 | 加冠 👑 |

- **攻击表现**：怪物贴近城墙时，汉字某一笔画**变形为元素武器**向下攻击 —— 金→剑刃 / 木→藤枪 / 水→水鞭 / 火→焰刀 / 土→岩锤。
- 颜色 + 字形双重编码，色弱玩家亦可分辨。

### 6.2 底部五行坞

| 状态 | 表现 |
|---|---|
| 未解锁 | 灰色方块 + 🔒 |
| 已解锁 | 元素色填充 + 白色汉字（印章反白） |
| **克制提示** | **红色脉冲描边 + 右上角「克」字**（依据场上怪物动态计算） |
| 选中 | 金色边框 + 外发光 |
| **连携激活** | **青色脉冲环 + 上方「连携」字** |

## 10. v2.3 操作层改造（已落地）

> 背景：真机反馈「相生看不懂 + 选完元素就干看着」。v2.2 只做了决策、没做操作。

### 10.1 核心规则（A+B 轻量版）

> 背景：真机反馈「相生看不懂 + 选完元素就干看着」。先试了 C（五元素战术弹），
> **实测不好玩**，回退为 A+B 轻量版——不做元素弹道差异，只让「点击有输出、相生看得见」。

| 项 | 规则 |
|---|---|
| 炮台 | 保持 **220ms/发** 自动射击（不降频，原有节奏不变） |
| 点击元素 | 立即补射 **1 发强化弹（3 发等效伤害）**，**共享 CD 1.2s** |
| CD 表现 | 所有已解锁图标画灰色扇形遮罩，选中的那个额外显示剩余秒数 |
| 相生指示 | 当前元素的**下一相生目标**图标上方显示青色 ▲ |
| 连携倒计时 | 选中图标外圈画青色收缩环（显示剩余时长） |
| 合击 | 连携窗口内点相生目标 → 该发变**合击弹**：×2.5 伤害、80px 范围、青色拖尾 + 「水生木 · 合击」飘字 |

### 10.2 为什么不做元素差异

C 版给每个元素配了不同弹道（火爆炸 / 金穿透 / 木连锁 / 水减速 / 土护盾），实测**不好玩**：

- 弹道差异稀释了「克制」这个唯一内核——玩家开始纠结「用行为还是用克制」
- 认知负担上升，与「极简」目标冲突
- 还需要重校整套 DPS 结构

结论：**操作感用「点击补射」解决，相生理解用「箭头 + 倒计时 + 合击反馈」解决**。
元素本身仍只有两条规则：克制、相生。

### 10.3 数值影响

| 玩法 | 发/秒 | 相对 v2.2 |
|---|---|---|
| 纯挂机 | 4.55 | 100%（不变） |
| 挂机 + 按 CD 点击补射 | 4.55 + 2.5 = **7.05** | **155%** |

> 炮台节奏未变，因此 **P6 的校准结论仍然有效**；点击补射是纯增益（鼓励操作），
> 若实测偏简单，只需调 `ELEMENT_TAP_CD`（1.2s → 1.6s）或点击等效（3 发 → 2 发）。
