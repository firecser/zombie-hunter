## 二、设置入口设计

### 2.1 方案选择

**方案A：在"主角"Tab内增加设置入口按钮**
- 在角色信息卡片下方增加"⚙️ 游戏设置"按钮
- 点击打开设置弹窗

**方案B：在商城Tab中增加设置页面**
- 商城内增加"设置"分类

**方案C：独立设置界面作为Tab**
- 复用"关于"Tab，点击显示设置内容

### 2.2 推荐方案

采用**方案A：设置弹窗**，因为：
- 符合游戏常规设计（设置通常以弹窗形式）
- 不增加Tab数量，保持界面简洁
- 复用现有弹窗组件，开发量小

## 五、技术实现

### 5.1 新增变量

```javascript
// 设置弹窗状态
let settingsModal = {
    show: false
};

// 当前设置项状态
let settings = {
    sound: true,      // 音效
    music: true,      // 音乐
    vibration: true   // 振动
};

// 设置页面状态（'main' | 'rules' | 'about'）
let settingsPage = 'main';

// 关于我们信息
const GAME_INFO = {
    name: '制霸新手村的骷髅怪',
    version: '1.0.5',
    developer: '个人开发者',
    email: 'example@email.com',
    description: '本游戏为冰雪世界塔防类微信小游戏...'
};
```

### 5.2 新增函数

| 函数名 | 功能 |
|--------|------|
| drawSettingsModal() | 绘制设置弹窗 |
| drawSettingsMainPage() | 绘制设置主页面 |
| drawSettingsRulesPage() | 绘制游戏规则页面 |
| drawSettingsAboutPage() | 绘制关于我们页面 |
| handleSettingsClick() | 处理设置弹窗内点击 |
| toggleSetting() | 切换设置项 |
| saveSettings() | 保存设置到本地 |
| loadSettings() | 加载设置从本地 |

### 5.3 振动功能实现（预留）

```javascript
// 振动反馈（微信API）
function vibrateFeedback() {
    if (settings.vibration && wx.vibrateShort) {
        wx.vibrateShort({ type: 'medium' });
    }
}

// 在适当的时机调用
function onZombieKill() {
    // ... 击杀逻辑
    vibrateFeedback(); // 添加振动反馈
}
```

### 5.4 数据持久化

```javascript
// 保存设置
function saveSettings() {
    wx.setStorageSync('zombieHunterSettings', JSON.stringify(settings));
}

// 加载设置
function loadSettings() {
    try {
        const saved = wx.getStorageSync('zombieHunterSettings');
        if (saved) {
            settings = JSON.parse(saved);
            soundEnabled = settings.sound;
            musicEnabled = settings.music;
        }
    } catch (e) {
        // 使用默认值
    }
}
```

## 七、入口集成

### 7.1 主角Tab增加设置入口

在 `drawMainMenuHero()` 中增加设置按钮：

```javascript
// 设置按钮
const settingsBtnY = cardY + cardH + 20;
ctx.fillStyle = 'rgba(255,255,255,0.1)';
roundRect(ctx, 20, settingsBtnY, screenWidth - 40, 45, 10);
ctx.fill();

ctx.fillStyle = '#fff';
ctx.font = '16px Arial';
ctx.fillText('⚙️ 游戏设置', screenWidth / 2, settingsBtnY + 28);
```

### 7.2 点击处理

在 `handleMainMenuTouch()` 中增加设置按钮点击检测：

```javascript
// 设置按钮点击
if (mainMenuTab === 'hero') {
    if (x >= 20 && x <= screenWidth - 20 &&
        y >= settingsBtnY && y <= settingsBtnY + 45) {
        settingsModal.show = true;
        settingsPage = 'main';
        return;
    }
}
```
