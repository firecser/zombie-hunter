# 18–30 岁中国玩家偏好梳理 & 本作「刺激感」改造清单

| 项 | 内容 |
|---|---|
| 触发 | 真机反馈：C 版「不好玩」→ A+B 版「还是不够刺激」 |
| 结论 | 问题不在「玩法规则」，在**爽点密度与反馈强度**。当前每分钟只有 1 个弱高潮，目标应做到 3–5 个 |
| 日期 | 2026-10-21 |

---

## 一、他们的注意力结构

| 维度 | 实际表现 | 对本作的含义 |
|---|---|---|
| 单次会话 | **3–8 分钟**（通勤 / 排队 / 睡前） | 单关 5.4 分钟没问题，但**前 30 秒必须出爽点** |
| 去留判断 | **3 秒**：首屏有没有动、有没有大数字 | 开局第一波就要能打出「一片数字」 |
| 爽点密度 | 每 **10–20 秒**一个小高潮，每 **1–2 分钟**一个大高潮 | 当前约 60–90 秒才有一次三选一，太稀 |
| 反馈优先级 | 视觉冲击 > 音效 > 数值 > 文字 | 现在最弱的是视觉冲击与音效层次 |
| 失败容忍 | 低；但**愿意为「差一点」重开** | 需要有「差一刀」的紧张感，而不是被慢慢磨死 |

---

## 二、被反复验证的六类「爽感来源」

| # | 来源 | 具体表现 | 参考品类 |
|---|---|---|---|
| 1 | **数值暴力** | 大数字、暴击、秒杀、伤害飘字刷屏 | 向僵尸开炮、传奇类 |
| 2 | **清屏掌控** | 一键清场、连锁爆炸、全屏白闪 | 吸血鬼幸存者、弹幕割草 |
| 3 | **成长可见** | 每 30 秒肉眼变强一次 | 土豆兄弟、roguelike 三选一 |
| 4 | **风险张力** | 连击将断未断、残血反杀 | 音游、连杀类 |
| 5 | **随机惊喜** | 掉落、暴击、稀有词条 | 刷宝类、开箱 |
| 6 | **社交货币** | 排行榜、称号、晒战绩 | 微信小游戏生态 |

> 关键洞察：**这六类里，本作目前只有第 3 类（三选一）勉强成立，而且是"隐形成长"——+15% 玩家感知不到。**

---

## 三、本作现在为什么「不够刺激」

| 爽感来源 | 现状 | 缺口 |
|---|---|---|
| 数值暴力 | 单发 61.6、点击 184.8、合击 363 | 数字**太小**；暴击有大字但没有演出；没有秒杀感 |
| 清屏掌控 | **完全没有** | 玩家从没体验过「一下清掉一片」 |
| 成长可见 | 每波三选一，+15% 隐形 | 缺少「立刻变强」的即时演出 |
| 风险张力 | 无连击、无连杀、无残血机制 | 打对打错只是快慢，**没有心跳** |
| 随机惊喜 | 三选一有随机 | 局内无掉落、无宝箱、无「哇」 |
| 社交货币 | 有排行榜 | 局内没有可晒的瞬间（五杀/无伤/极限反杀） |

### 一句话诊断

> **现在的游戏是"正确的"，但不是"爽的"。**
> 玩家做对了所有事（读色、切元素、点合击），得到的反馈只是"怪死得快一点"。

## 四、改造清单（按 ROI 排序）

### P8-1 · 打击感三件套 ⭐ 最高 ROI（约半天）

| 项 | 做法 | 感知提升 |
|---|---|---|
| 顿帧 Hit-stop | 命中/暴击时全局冻结 **35–50ms** | 极大（"打到了"的手感） |
| 屏幕震动 | 暴击 3px / 合击 6px / 大招 12px，衰减 200ms | 极大 |
| 震动 API | `wx.vibrateShort({type:'light'})` 暴击、`'heavy'` 合击/大招 | 大（手机独有） |
| 暴击演出 | 伤害数字 28px→40px、加粗、红金渐变、上飘更远 | 大 |

> 这一条**不改任何数值**，纯反馈，风险最低、体感提升最明显。

### P8-2 · 连杀倍率 ⭐ 最高 ROI（约 1 天）

| 项 | 规则 |
|---|---|
| 连杀计数 | 连续用**克制元素**击杀 → 连杀 +1；用错元素击杀 → **立即清零** |
| 倍率 | 伤害 ×(1 + 0.08 × 连杀)，上限 **×2.0**（连杀 12.5 封顶） |
| 演出 | 屏幕边缘火焰描边渐强；每 5 杀弹一次「五杀 / 十杀 / 超神」；音调随连杀升高 |
| 为什么有效 | 把「读色」从"对错判断"变成**连续性挑战**，制造"不能断"的紧张感 |
| 风险 | 会放大错配惩罚，需与 P6 数值一起看（建议先只加成、不惩罚） |

### P8-3 · 五行归元（大招）⭐ 峰值爽点（约 1 天）

| 项 | 规则 |
|---|---|
| 充能 | 每次**克制击杀 +1 能量**，合击 +5；满 **100** 可放 |
| 释放 | 点击坞上「归元」按钮 → **全屏清怪**（伤害 = 当前元素 8 发等效 × 全部在场怪）|
| 演出 | 0.6 秒慢动作（timeScale 0.25）→ 全屏白闪 → 五行色环扩散 → 数字雨 |
| 频率 | 每关约 **1–2 次**（不喧宾夺主） |
| 为什么有效 | 给玩家一个「攒着、等一波大的」的目标，制造**延迟满足**的爽点 |

### P8-4 · 掉落与吸附（约半天）

- 击杀掉金币/能量球，**自动吸附**到城墙（飞行轨迹 + 叮叮音效）
- 每波清空掉一个**宝箱**（3 选 1 金币 / 能量 / 临时增伤）
- 目的：填满"走路也要有反馈"的空隙

### P8-5 · Boss 演出（约 1 天）

- 出场 3 秒警告横幅 + 红屏脉冲
- 独立血条（顶部）+ 破防阶段（血量 50% 时闪光、攻速提升）
- 击杀慢动作 + 爆金币雨 + 「BOSS 击破」大字

### P8-6 · 局内称号（约半天）

- 五杀 / 十杀 / 超神 / 无伤通关 / 极限反杀（城墙 <10% 时清场）
- 结算页展示，可分享

## 五、建议的执行顺序

| 阶段 | 内容 | 工作量 | 预期效果 |
|---|---|---|---|
| **P8a** | 打击感三件套 + 连杀倍率 | **1.5 天** | 从"正确"变"有手感"，预计解决 60% 的"不刺激" |
| **P8b** | 五行归元大招 + 掉落吸附 | 1.5 天 | 补上"清屏"和"惊喜"两个缺口 |
| **P8c** | Boss 演出 + 称号 | 1.5 天 | 社交货币与关卡记忆点 |

> **先做 P8a**：不改数值、不加新系统、不动五行规则，只加反馈层——这是风险最低、最可能一次见效的改法。

---

## 六、三条不能破的红线

1. **元素仍只有两条规则**（克制 / 相生），连杀与归元都是**放大器**，不是新规则
2. **不能把游戏变成音游**：连杀断了只是清零倍率，不惩罚血量
3. **爽点必须服务于「读色」**：连杀靠克制击杀积累，归元靠克制击杀充能——所有爽感都在强化同一个内核

## 七、已落地：v2.4「五行轮转」（2026-10-21）

用户拍板「什么都可以改，放开思想」后，直接把这一页的核心机制做进游戏：

### 7.1 新核心循环

> **克制击杀积「印」→ 相生切换引爆 → 五连引爆触发「五行轮转」清屏**

| 环节 | 规则 | 对应爽感 |
|---|---|---|
| **积印** | 用克制元素击杀 → 该元素「印」+1（上限 30） | 成长可见 |
| **连杀** | 克制击杀累计连杀，伤害 ×(1+0.06×连杀)，**17 层封顶 ×2.0**；错配击杀立即清零；12s 无击杀衰减 | 风险张力 |
| **引爆** | 切到相生目标时，消耗上一元素的全部印 → **全场伤害 = 单发×印数×0.8** | 清屏掌控 |
| **轮转** | 6s 内连续引爆 5 次 → **全屏 ×3 + 0.5s 慢动作 + 白闪 + 震屏 14px** | 峰值高潮 |

### 7.2 打击感三件套（已落地）

| 项 | 实现 |
|---|---|
| 顿帧 | `hitStopUntil`：命中瞬间冻结（预留接口，后续接暴击/大招） |
| 震屏 | `shakeMag/shakeUntil`：普攻 0 / 五杀 4px / 引爆 6px / 轮转 14px |
| 震动 | `wx.vibrateShort`：五杀 light / 引爆 medium / 轮转 heavy |
| 暴击大字 | 26px → **34px** + 深色描边 |
| 慢动作 | 轮转时 `dt × 0.3`，持续 0.5s |
| 全屏闪光 | 轮转时 260ms 元素色闪白 |

### 7.3 HUD

- 坞图标左上角显示该元素的「印」数
- 坞上方显示「×1.36  连杀 6」
- 连杀到 5 / 10 / 20 弹「五杀 / 十杀 / 超神」
