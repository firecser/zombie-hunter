## P9a · M3 弹道成长

| 项 | 规则 |
|---|---|
| 基础弹道 | 1 |
| 元素精通 | Lv5 → +1；Lv9 → +1（共 1→3） |
| 词条「连发」 | 每级 +1（最多 +3，P9b 接入） |
| 上限 | **6** 条，扇形散开（±0.14 rad/条） |
| 验收 | 单发命中数随精通上升；弹道数不超过 6 |

## P9b · M2-1 词条系统

| 词条 | 效果（每级） | 上限 |
|---|---|---|
| 连发 | 弹道 +1 | 3 |
| 穿透 | 穿透 +1 | 3 |
| 爆裂 | 命中 40+10×级 范围伤害 | 3 |
| 霜冻 | 命中减速 0.8+0.4×级 秒 | 3 |
| 灼烧 | 命中点燃 2s，每秒 8%×级 伤害 | 3 |
| 弹射 | 命中后弹向 1 个附近目标 | 3 |

- 三选一池 = 当前元素精通卡 + 6 词条卡 + 进化卡
- 权重：精通 1.2 / 词条 1.3 / 进化 2.0

## P9c · M2-2 进化（3 级 × 元素）

| 词条Ⅲ | 元素 | 超武 | 效果 |
|---|---|---|---|
| 连发 | 火 | **火焰喷射** | 弹体加大、命中 60px 爆炸 + 点燃 |
| 穿透 | 金 | **穿甲激光** | 穿透 8、弹速 ×1.5、弹体细长 |
| 弹射 | 木 | **藤蔓领域** | 命中生成 70px 减速区 2s |
| 霜冻 | 水 | **冰环** | 命中 80px 减速 2.5s + 冰封 0.4s |
| 灼烧 | 土 | **熔岩地带** | 命中 70px 爆炸 + 点燃 |

- 进化绑定「进化时选中的元素」，一局只能进化一次
- 进化后该元素子弹换色/换形态

## P9d · M1 走位

| 项 | 规则 |
|---|---|
| 操作 | 在战场区域拖动 → 角色左右跟随手指（限制在城墙前 ±120px） |
| 与坞的冲突 | 坞区域点击优先判定为切元素，不触发移动 |
| 收益 | 经验球改为「角色 70px 磁吸拾取」，走位=更快升级；子弹起点随角色移动，可换列输出 |
| 不做 | 角色血量/失败条件（仍以城墙为准，避免关卡重做） |

## P9e · 数值重校

- 词条 + 弹道使 DPS 显著上升，需按「精通+词条+连杀+引爆」重扫 6 档
- 可能调整：点击等效 3→2 发、连杀上限 ×2.0→×1.6、体型血上调

## 落地结果（2026-10-21，P9a–P9d 已完成）

### 代码改动

| 模块 | 实现 |
|---|---|
| **M3 弹道** | `bulletCountFor(el)`：`1 + min(2, floor((Lv-1)/4)) + 词条连发 + 进化2`，上限 6；`spawnBulletFan()` 扇形 ±0.14 rad/条 |
| **M2 词条** | `PERK_DEFS` 6 种（连发/穿透/爆裂/霜冻/灼烧/弹射）+ `perks` 状态；三选一池 = 精通卡 + 6 词条卡 + 进化卡 + 3 通用保底 |
| **M2 进化** | `EVOLUTIONS` 5 条：连发Ⅲ+火=火焰喷射 / 穿透Ⅲ+金=穿甲激光 / 弹射Ⅲ+木=藤蔓领域 / 霜冻Ⅲ+水=冰环 / 灼烧Ⅲ+土=熔岩地带 |
| **命中特效** | `applyPerkHit()`：爆裂范围伤、霜冻减速、灼烧点燃、弹射跳怪、进化形态（爆炸/穿透/减速区/冰封/燃烧） |
| **M1 走位** | `onTouchMove`：战场区域拖动 → `player.x` 跟随（44 ~ screenWidth-44）；坞区域不触发 |
| **走位收益** | 经验球磁吸半径 **200px**（原来无限距离），必须走过去才吃得到 |
