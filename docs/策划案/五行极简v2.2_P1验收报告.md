## 二、发现并修复的 3 个 Bug

### BUG-1（严重）双系关卡怪物退化成灰色「僵」，五行编码全部丢失

- **影响范围**：第 7–10 章 = **第 37–60 关，共 24 关**。
- **现象**：这些关卡的怪渲染成灰色「僵」，既没有元素汉字也没有元素色，玩家无从判断该切哪个元素；攻击时还退回「爪」而不是元素武器。
- **根因**：`STAGES` 对双系章写的是 `element:'normal'` + `elements:['金','水']`（`buildStages` L251–252），而 `drawZombie` 只读 `zombie.element` → 命中 `WUXING_GLYPH['normal']='僵'`。
- **修复**：主字形/主色/武器改为「取 `elements[0]` 兜底」；并在怪物右上角补一个**第二元素小字**（半环颜色单看不够直观）。
- **验证**：`smoke_p1_fix.js` 记录 `fillText` 实参，断言双系怪同时绘制 `金`+`水` 且**不出现** `僵`。

### BUG-2（严重，真机必现）底部未处理安全区，坞图标被系统手势吃掉

- **现象**：iPhone 全面屏（底部 Home 指示条约 34px）上，坞图标下沿有约 19px 落在 810–844 区，点击会被系统上滑手势抢走。
- **根因**：项目只有 `SAFE_TOP_OFFSET`，从未读取 `safeArea.bottom`；坞顶写死 `screenHeight - DOCK_H`。
- **修复**：读取 `safeArea.bottom` 得 `SAFE_BOTTOM_OFFSET`；新增 `DOCK_HEIGHT` / `DOCK_TOP` 统一基准，坞/控制按钮/炸弹全部按 `DOCK_TOP` 排版；坞底栏向下延伸进安全区避免黑边。
- **验证**：模拟 844 屏 + `safeArea.bottom=810`，图标底 794.8 ≤ 810；非全面屏（inset=0）时坞顶回到 751，无回归。

### BUG-3（中）买量素材演示模式炸弹坐标未跟随新按钮位置

- **现象**：素材演示的引导闪光/箭头与爆炸原点仍指向旧位置（屏幕右下角 `screenHeight-48`），而炸弹按钮已被 P1 移到坞上方 → 引导指向空白处。
- **根因**：`drawAdDemoGuide` L4014、`adDemoBombExplosion` L6888 写死坐标。
- **修复**：两处改用 `BOMB_BTN_X` / `BOMB_BTN_Y`。
- **验证**：源码级断言，`screenHeight - 48` 残留计数必须为 0。
