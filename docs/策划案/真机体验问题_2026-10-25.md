# 真机体验问题诊断（L1 · 2026-10-25）

> 依据：真机截图（第1关「冰雪初现」1/6，Lv.11，BOSS 22401/22401）
> 结论：**主要问题不是玩法，是"信息打架"——屏幕上有 6 个东西在抢注意力，玩家看不清该看哪。**

---

## 一、最伤体验的 5 个问题（按严重度）

### P0-1 汉字怪物过大，且全部同款

| 项 | 现状 |
|---|---|
| 最大「火」字 | 宽约 **210 / 484 ≈ 43% 屏宽** |
| 普通「火」字 | 约 **19% 屏宽** |
| 区分度 | **同字、同色、同粗细**，只有大小差别 |

**后果：**
- 一只大字直接**盖住左上角关卡信息**（截图里「火」压住了 1/6 与金币）
- 满屏橙色块，**看不出哪只是快怪/坦怪**，只能靠移动速度反应，来不及
- 玩家无法快速判断"该切哪个元素"，五行策略被视觉噪音吃掉

### P0-2 掉落物连成一串，像"珠子"

中段一条 **8–10 个黄色圆点**横着排开，与怪物重叠。

- 分不清是金币、经验、还是怪物的装饰
- 拾取需要走位，但看不出哪个值得去拿
- 与橙色怪同色系，**对比度不足**

### P0-3 顶部信息区三层叠在一起

```
[第1关 冰雪初现 1/6]          BOSS 22401/22401
[Lv.11  426金币  700  13/20]  ████████████░░
              [已连接]  ← 悬浮在战场中央
```

- BOSS 血条压在关卡信息右侧，两者**同一水平线**
- 「已连接」黑色横幅**横在战场中央**，遮挡视野
- 顶部实际被占了约 **100px（9% 屏高）**，但信息密度很低

### P0-4 右下角三个焦点互相抢

| 元素 | 问题 |
|---|---|
| 炸弹按钮（红环 + ▶） | 尺寸大，红环最抢眼 |
| 「一发清屏！点击炸弹」 | 两行文案，长期常驻 |
| 五行坞「30 水 / 30 火」 | 字号小、信息密 |

玩家的视线在右下角被拉扯，**真正该看的"来袭怪"反而在左上/中上**。

### P0-5 城墙"命"看不出来

- 城墙是一整条灰砖，**没有任何破损表现**
- 上方 3 格（绿/灰/灰）是独立血条，**和城墙没有视觉关联**
- 玩家不知道"墙还剩几条命"，也不知道"破了会怎样"

## 三、建议的修复顺序

### 第一批（视觉降噪，1 天内可完成）

1. **怪物尺寸分级 + 上限**
   - BOSS ≤ **28%** 屏宽，坦 ≤ 20%，普通 ≤ 14%，快怪 ≤ 11%
   - 大字改**描边空心**（只描边不填充），避免糊成色块

2. **掉落物改造**
   - 金币/经验**拉开间距**（当前横向太密）
   - 经验=蓝色小圆，金币=金色方孔钱，**不同形状**
   - 同屏上限 ≤ 12 个，超出合并成一个大球

3. **顶部 HUD 收拢**
   - 关卡信息压成 **一行**（关卡 + 波次 + 金币）
   - BOSS 血条**下移 12px**，独占一行
   - 「已连接」改为**顶部细条**，2 秒自动消失

### 第二批（表现力，2 天）

4. **城墙做"破损"**
   - 3 格命 = 城墙**三段砖块**，破一格塌一段（缺口 + 碎石）
   - 删掉独立血条

5. **右下角减法**
   - 炸弹按钮缩到当前 **70%**
   - 「一发清屏」只在**前 3 关**显示，之后不再常驻

### 第三批（辨识度）

6. BOSS 加名字/阶段（如「火·将」→「火·王」）
7. 伤害数字改为**跟随怪物**，不贴边
8. L1 主题统一：雪地 + 火怪改为"雪地被灼烧"的地面表现

---

## 四、一句话总结

> 现在的问题是**"每样东西都在喊"**：大字怪、红炸弹、黄掉落、黑提示、橙 BOSS 条。
> 先把**怪物尺寸**和**掉落物**降噪，画面立刻会清爽一半。
