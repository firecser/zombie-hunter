# 五行极简 v2.3 · 操作层改造方案（解决「相生模糊 + 干看着」）

| 项 | 内容 |
|---|---|
| 触发 | 真机反馈：① 相生看不懂 ② 选完元素后大部分时间在干看着 |
| 性质 | **设计层问题**，非 bug。当前 v2.2 的「固定炮台自动射击」把玩家参与度压到了最低 |
| 日期 | 2026-10-20 |

---

## 一、问题诊断

### 1.1 为什么相生看不懂

| 现状 | 问题 |
|---|---|
| 相生只体现为「切到被上个元素所生的元素 → 4s 内 +20%」 | 玩家**看不到**下一个该点谁 |
| 坞上只有选中金边 + 克制红脉冲 | 没有「相生目标」的指向 |
| 连携视觉只有青色脉冲环 + 一次性横幅 | 没有**结果反馈**（伤害跳没跳、跳了多少） |
| 相生与克制是两个独立判断 | 玩家脑子里要同时算「克制谁」和「下一步生谁」，认知超载 |

### 1.2 为什么干看着

- 炮台 220ms 自动射击，每秒 4.55 发——**输出与玩家操作无关**。
- 玩家唯一动作：怪物入场 → 点对应元素 → 继续看。
- 单关 5.4 分钟里，实际操作次数 ≈ 30–50 次点击，且每次之间**没有任何需要持续关注的东西**。

> 结论：v2.2 把「读色选克」做对了，但只做了**决策**、没做**操作**。
> 一个只有决策没有操作的游戏，在休闲品类里会被判定为"看动画"。

---

## 二、三个方案

### 方案 A · 点击即输出（最小改动，先止血）

| 项 | 内容 |
|---|---|
| 核心 | **点击元素 = 立即打出 1 发强化弹**（3 发等效伤害），该元素进入 1.2s 小 CD（图标画灰色扇形） |
| 自动炮台 | 保留 220ms，作为保底 |
| 相生 | 在连携窗口内点击「相生目标」→ 该发变成**合击弹**：伤害 ×2.5、范围 80px、青色拖尾 + 「合击」飘字 |
| 认知辅助 | 选中元素后，**下一个相生目标图标加青色小箭头**（唯一新增信息） |
| 改动量 | **小**，约 120 行（坞点击 + CD 环 + 合击弹 + 箭头） |
| 手感 | 手指有事做，点击有即时反馈；但战术维度仍然只有「克制」一个 |
| 风险 | 连点可能在 1.2s CD 内空点，需要 CD 环明确提示 |

### 方案 B · 相生链可视化 + 接链（中等，专治「看不懂」）

| 项 | 内容 |
|---|---|
| 核心 | 坞上方画一条**五行环**（水生木→木生火→火生土→土生金→金生水），当前元素高亮，**下一环闪烁** |
| 接链 | 在连携 4s 内切到下一环 → 链数 +1，增伤 1.2 → 1.35 → 1.5 → 1.65（最多 4 链），断链归 1.2 |
| 反馈 | 每次接链：环上画连接线 + 屏幕上方「连携 ×3」+ 炮口颜色变化 |
| 改动量 | **中**，约 200 行（环绘制 + 链状态 + 增伤叠加 + 衰减） |
| 手感 | 相生终于"看得懂、有追求"；但**依旧是点一下就完**，干看着的问题只解决一半 |
| 风险 | 信息量上升，与"极简"有张力；环在小屏上要够大才不会点错 |

### 方案 C · 5 元素战术弹（推荐，同时解决两个问题）

| 项 | 内容 |
|---|---|
| 核心 | **点击元素 = 释放该元素的战术效果**，共享 1.2s CD；自动炮台降频到 **1.4s/发**（只做保底，不再主导输出） |
| 元素差异 | 火：落点爆炸（范围 70px，1.2×）<br>金：直线穿透（最多 3 个，0.8× each）<br>木：连锁 2 跳（0.6× each）<br>水：命中减速 40% / 2s（容错）<br>土：不发射，城墙 +150 护盾 3s（独立 6s CD） |
| 相生 | 连携窗口内按相生顺序放两个元素 → **合击**：统一「全屏范围 2.5× + 元素色特效 + 飘字」，五种合击只差颜色与文案 |
| 认知辅助 | ① 坞上相生箭头 ② 连携倒计时环 ③ 首次遇到某元素时，怪物头顶提示「用 X 打」 |
| 改动量 | **大**，约 400 行（子弹行为分支 + 减速/护盾状态 + 合击 + UI） |
| 手感 | 从「看颜色点一下」变成「选战术」：怪多→火、排队→金、快怪→水、要崩→土 |
| 风险 | 与"极简"目标有张力；需要一轮数值重校（DPS 结构变了） |

## 三、对比

| 维度 | A 点击即输出 | B 相生链 | C 战术弹 |
|---|---|---|---|
| 解决「干看着」 | ★★★☆ | ★★ | ★★★★ |
| 解决「相生看不懂」 | ★★★ | ★★★★ | ★★★★ |
| 改动量 | 小 | 中 | 大 |
| 与「极简」的一致性 | 高 | 中 | 中低 |
| 需要重校数值 | 否 | 轻微 | **是** |
| 认知负担 | 低 | 中 | 中高 |

---

## 四、建议

**先做 A + B 的合并轻量版**（一次改动同时止血两个问题）：

1. **点击即输出**：点击元素立刻打 1 发强化弹（3 发等效），1.2s CD，图标画 CD 扇形；
2. **相生可视化**：选中元素后，下一相生图标加青色箭头 + 连携倒计时环；
3. **合击反馈**：连携窗口内点相生目标 → 该发变「合击」（×2.5、80px 范围、青色拖尾、飘字）；
4. **不引入**元素弹道差异（留给 C）。

预估 **≈220 行**，不动自动炮台节奏、不需要重校数值，风险可控。

若这版仍觉得"选择太单一"，再上 **C**（战术弹），那时需要重跑 `sim_v22_real.js`。

## 六、落地结果（2026-10-21，方案 C 全量）

用户拍板：**1 选 C ／ 2 炮台降频 ／ 3 每元素独立 CD ／ 4 五元素各自合击**。

### 6.1 已实现

| 项 | 实现 |
|---|---|
| 炮台降频 | `ELEMENT_AUTO_FIRE_RATE = 600ms`（原 220ms），只做保底 |
| 点击释放 | 点击元素立即释放该技能，**每元素独立 CD 2.5s**（土 6s） |
| 火 | 战术弹：命中点 70px 爆炸（范围 0.7×）+ 点燃 3s |
| 金 | 战术弹：穿透 3 个目标（`piercing: 2`） |
| 木 | 战术弹：命中后连锁 2 跳（0.6× each） |
| 水 | 战术弹：命中 + 55px 范围减速 2s |
| 土 | 不发射：城墙 50% 减伤 3s + 爆炸特效 + 「护盾」飘字 |
| 合击 | 相生顺序点击 → 先合击再放技能，**五种各自独立状态**：<br>水生木·藤蔓 = 定身 1s<br>木生火·燎原 = 燃烧 3s<br>火生土·熔岩 = 减速 2s<br>土生金·金锐 = 破甲 +30% 3s<br>金生水·寒潮 = 冰缓（定身 0.5s + 减速 3s） |
| 认知辅助 | 坞图标画 CD 遮罩 + 剩余秒数；当前元素的**下一相生目标**显示青色 ▲ |

### 6.2 DPS 结构变化（**需要重校**）

以「每发基础伤害 = 1」计，射击频率：

| 玩法 | 发/秒 | 相对 v2.2（4.55/s） |
|---|---|---|
| 完全挂机（只靠炮台 600ms） | 1.67 | **37%** |
| 只点单一元素（2.5s CD） | 2.87 | **63%** |
| 五元素轮点（各自独立 CD） | **7.67** | **169%** |

> 设计意图达成：**挂机变弱、操作变强**。但 P6 的校准是按 4.55 发/s 恒定输出的，v2.3 后：
> - 挂机流会比 P6 表更早崩（正确，鼓励操作）
> - 轮点流比 P6 表强 69%（可能偏简单）
>
> **建议下一轮（P6c）**：把 `sim_v22_real.js` 加上「点击输出」项，按 **轮点 7.67 发/s** 重扫 6 档，必要时把点击等效从 3 发降到 2 发、或 CD 2.5→3s。

### 6.3 验证

```
node --check game.js   → SYNTAX_OK
smoke_p7.js            → 4 项 PASS
p1 / p1_fix / p2 / p3 / p4 / p5 → 全部 PASS（无回归）
```

## 七、回退记录：C → A+B（2026-10-21 真机反馈）

用户真机试玩 C 版后反馈：**「不好玩」**，要求改回推荐的 A+B 轻量版。

### 7.1 为什么 C 不好玩（复盘）

| 问题 | 说明 |
|---|---|
| 稀释唯一内核 | 弹道差异让玩家开始想「用行为还是用克制」，而不是「读色选克」 |
| 认知过载 | 5 元素 × 5 行为 × 5 合击 = 25 种组合，超出休闲定位的承载 |
| 需要重校 | 炮台降频 + 点击输出改变了整套 DPS 结构（37%/63%/169%） |

### 7.2 A+B 版最终形态

| 项 | 规则 |
|---|---|
| 炮台 | **220ms 不变** |
| 点击元素 | 立即补射 **1 发强化弹（3 发等效）**，**共享 CD 1.2s** |
| CD 表现 | 所有已解锁图标灰色扇形遮罩；选中的显示剩余秒数 |
| 相生指示 | 下一相生目标图标青色 ▲ |
| 连携 | 选中图标外圈青色收缩环（剩余时长） |
| 合击 | 连携窗口内点相生目标 → ×2.5 伤害、80px 范围、青色拖尾 + 飘字 |

### 7.3 代码变更（相对 C 版）

| 项 | C 版 | A+B 版 |
|---|---|---|
| `ELEMENT_AUTO_FIRE_RATE` | 600 | **220**（实际等同于不降频） |
| `ELEMENT_TAP_CD` | 每元素 2.5s / 土 6s 对象 | **共享 1200ms 数值** |
| `elementTapReadyAt` | 每元素时间戳对象 | **单一时间戳** |
| `castElementSkill` | 5 元素各异（爆炸/穿透/连锁/减速/护盾） | **统一强化弹**，仅合击时 ×2.5 |
| `castCombo` / `COMBO_DEF` | 五种各自状态 | **删除** |
| `tapShieldUntil`（土护盾） | 有 | **删除** |
| `applyTapHitEffect` | 爆炸/减速/连锁 | **仅合击**：80px 范围 + 飘字 + 爆炸环 |

### 7.4 验证

`smoke_p7.js` 重写为 6 项：炮台 220ms / 点击 3 发等效 / 共享 CD / 合击 ×2.5 / 80px 范围内受伤 / 普通弹无范围伤 —— 全部 PASS。
