## 四、可以进入数值/其他阶段了吗？

**可以，但有顺序**。三套机制叠加后，DPS 已不是 P6 校准的那个模型：

| 变量 | 对 DPS 的影响 |
|---|---|
| 弹道 1→6 | **最高 ×6** 的弹幕量 |
| 词条（爆裂/弹射/穿透） | 对群再放大 1.5–2× |
| 连杀 ×2.0 | 全局 ×2 |
| 印引爆 | 单次爆发 ≈ 单发×印数×0.8 |
| 眩晕停火 0.7s | 约 −2% 总输出（惩罚项） |

→ **P9e 数值重校是必做项**，否则 L1 可能过难、L60 必过易。

### 建议顺序

| 步骤 | 内容 | 产出 |
|---|---|---|
| **1. 真机记录（半天）** | 打 L1 / L30 / L60 各一局，记 4 个数：单关时长、每波升级数、拾取率、眩晕次数 | 真实基准 |
| **2. 模拟器重校（P9e）** | 把「弹道/词条/连杀/引爆」折算成 DPS 系数写进 `sim_v22_real.js`，重扫 6 档 | 新难度表 |
| **3. 落表微调** | 按结果调 `healthMult` / 体型血 / 经济 | 可发布数值 |
| 4. 其他 | Boss 演出、掉落宝箱、称号、排行榜分享 | 后续 |
