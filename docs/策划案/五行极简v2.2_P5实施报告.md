## 五、5.4 死代码清理：**暂缓，原因如下**

已确认无调用点、可安全删除的：

| 项 | 现状 |
|---|---|
| `CREATURE_VISUAL` | 仅定义，无引用 |
| `drawSkillUI()` | 仅定义，P1 起已无调用点 |
| `shootBase()` / `shootAttribute()` / `shootWood()` | 仅定义，P2 起已无调用点 |

但这三组函数合计约 600 行，且 `shootWood` / `shootAttribute` 内部还引用 `woodMods()` / `freezeMods()` /
`pendingWoodLogs` / `updateLogs` 等一串辅助系统；`getPlayerDpsIndex()` 等仍在读这些修正。
盲目整块删除容易在真机运行时炸出引用错误，而当前测试只覆盖绘制/战斗核心，覆盖不到所有分支。

**建议**：把 5.4 作为独立一轮「死代码清理」执行——先用引用计数清单确认，再逐块删除 + 每删一块跑一次全量冒烟 + 真机进战斗验证。
