# 已知问题（可忽略）

> 记录「看着像 bug、实际无害」的现象，避免以后重复排查。

## 1. 广告前后控制台刷 `xxxTextView:fail`

| 现象 | `insertTextView:fail position.top should be Number` / `updateTextView:fail <id> not found` / `insertTextView:fail parent <id> not found` |
|---|---|
| 出现时机 | 播放激励视频前/后（盾兵、守将复活、金币×2 等任意广告位） |
| 归属 | **微信 SDK 内部**：广告层关闭后重建原生 text 视图，父节点已销毁 |
| 影响 | **无**。广告正常播放、奖励正常到账、游戏正常继续 |
| 已做的缓解 | ① `onClose` 只注册一次；② 广告流程改用画布提示；③ 广告前收起原生游戏圈按钮；④ `statusBarHeight` 强制数字 + 坐标 `isFinite` 校验；⑤ `wx.showToast` 广告期抑制 + 去抖 |
| 结论 | **忽略**。开发者工具会显示，真机通常不显示 |

**判断是不是真问题，只看三条：**
1. 广告能不能正常拉起并看完
2. 奖励到不到账（盾兵出现 / 护城格恢复 / 金币翻倍）
3. 回到游戏是否正常继续（不黑屏、不卡暂停）

三条都正常 → 报错可无视。
