# 好友排行榜 · 真机自测清单

> 开放数据域在**开发者工具里表现不完整**（好友数据常为空），必须用**体验版 + 真机 + 至少 1 个在玩的好友**验证。

## 一、上线前检查（代码侧已就位）

| 项 | 位置 | 状态 |
|---|---|---|
| `game.json` 声明开放数据域 | `"openDataContext": "openDataContext"` | ✅ |
| 子域脚本 | `openDataContext/index.js` | ✅ 拉取 `getFriendCloudStorage` + 画 `sharedCanvas` |
| 成绩上传 | `victory()` / `gameOver()` → `submitBestScore()` | ✅ 只在有提升时写 |
| 主域渲染 | `postMessage({type:'render'})` + `drawImage(openDataCanvas)` | ✅ |
| 三 Tab | 战绩 / 守关 / 好友 | ✅ |

## 二、真机自测步骤

1. **上传体验版**，用两个微信号（A 玩过、B 是 A 的好友）
2. A 打一局并通关 → 关闭重开 → 主界面 → 排行榜 → **好友** Tab
3. 期望：能看到 **B 的昵称 + 头像 + 第 X 关 + 战力**
4. B 也玩一局 → A 再进好友榜 → 应看到 B 的成绩刷新

## 三、按现象定位

| 现象 | 原因 | 处理 |
|---|---|---|
| 显示「当前环境不支持好友榜」 | `wx.getOpenDataContext` 不可用 | 确认基础库版本 ≥ 2.x，真机运行 |
| 一直「还没有好友上榜」 | 好友没玩过 / 好友未授权 / `best` 键无数据 | 让好友先玩一局 |
| 自己不在榜上 | 成绩未上传成功 | 看 Console 是否有 `setUserCloudStorage` 报错 |
| 榜单空白但无报错 | sharedCanvas 尺寸为 0 | 检查渲染区高度是否 >0 |
| 头像不显示 | 头像域名未加载 | 头像走 `wx.createImage`，需在小游戏后台配置域名（通常默认放行） |

## 四、隐私红线

| 项 | 要求 |
|---|---|
| 好友数据用途 | **只用于本机渲染榜单**，不上传、不落库、不参与任何统计 |
| 展示字段 | 昵称、头像、关卡、战力（均为用户公开资料） |
| 未授权用户 | 不显示，不做任何提示 |
| 隐私指引 | 需在《隐私保护指引》中说明「获取好友公开信息用于排行榜展示」 |

> 提审前请以微信官方最新文档核对开放数据域与隐私要求。
