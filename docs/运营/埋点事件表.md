# 埋点事件表（微信自定义分析）

> 代码已接入 `wx.reportAnalytics`。**需要在微信后台注册同名事件与参数**，否则数据不会进报表。

## 一、事件一览

### 1. `ad_show` — 激励视频开始播放

| 参数 | 类型 | 含义 |
|---|---|---|
| `slot` | string | 点位：`bomb` / `shield` / `revive` / `reroll` / `chest` / `double_gold` |
| `level` | number | 关卡号 |
| `wall` | number | 当前护城格（0–3） |
| `revive` | number | 是否已用过复活（0/1） |

### 2. `ad_result` — 激励视频结束

| 参数 | 类型 | 含义 |
|---|---|---|
| `slot` | string | 同 `ad_show` |
| `level` | number | 关卡号 |
| `ok` | number | **1=看完发奖 / 0=中途关闭** |
| `ms` | number | 播放时长（毫秒） |

### 3. `level_end` — 单局结束

| 参数 | 类型 | 含义 |
|---|---|---|
| `level` | number | 关卡号 |
| `win` | number | 1=通关 / 0=失败 |
| `dur` | number | 本局时长（秒） |
| `leaks` | number | 漏怪数 |
| `lives` | number | 结束时剩余护城格 |

---

## 二、能算出来的关键指标

| 指标 | 算法 |
|---|---|
| **点位转化率** | `ad_result(ok=1) / ad_show`，按 `slot` 分组 |
| **完播率** | 同上（1 − 中途关闭率） |
| **人均广告次数** | `count(ad_result, ok=1) / count(distinct 用户)` |
| **单局广告数** | `count(ad_show) / count(level_end)` |
| **关卡完成率** | `level_end(win=1) / level_start`（可先用 `level_end` 总数近似） |
| **漏怪分布** | `level_end.leaks` 直方图 → 判断难度是否合理 |
| **单局时长** | `level_end.dur` 中位数（目标 300s 左右） |

---

## 三、微信后台注册步骤

1. 微信公众平台 → **数据分析 → 自定义分析 → 事件管理**
2. 新建事件，事件名填 `ad_show` / `ad_result` / `level_end`
3. 为每个事件添加对应参数（名称与上表**完全一致**，类型选「字符串」或「数值」）
4. 保存后约 1 小时生效

> 参数名不一致 = 数据丢失。改代码里的 key 必须同步改后台。

## 四、真机调试

```js
trackBuffer            // 最近 60 条 { e, d, t }
trackBuffer.filter(x => x.e === 'ad_result')
```
