# 版本变更整理：v1.1.33 – v1.1.54

> 整理日期：2026-08-20
> 目的：理清 v1.1.33–v1.1.54 区间做过的内容，并核对**当前可读 `game.js`**（去混淆构建）实际包含情况。

## 一、重要背景（先读）

- v1.1.33 起，微信「游戏深度保护」插件把混淆/minified 产物**写回 `game.js`** 并提交 git。因此 git 里 v1.1.33–v1.1.54 的每个 tag 对应的 `game.js` 都是**混淆产物**，不是可读源码。
- 当前工作区 `game.js` 是用户用去混淆工具还原的**早期间构建**（约 v1.1.33–v1.1.39 区间）：含天赋树 v4.1–v4.6 竖版 UI、18 节点扁平天赋树、金币制升级弹窗、五行技能系统、战斗力；但**不含** v1.1.40 分栏子页、v1.1.41 五行深养成链、v1.1.53/54 失败弹窗变强。
- 结论：区间内绝大多数功能**曾做过并提交 git**，但不在当前可编辑源码里。要做新功能需基于当前可读 `game.js` 重新落地缺失部分，或恢复更晚的去混淆构建。
