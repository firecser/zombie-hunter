## 二、游戏系统架构

### 2.1 核心循环
```
玩家进入战斗 → 自动射击僵尸 → 击杀获取经验/金币 → 升级选择技能 → 战斗计时5分钟 → 通关/失败
```

### 2.2 游戏状态机
```
start → mainMenu → playing ↔ paused
                    ↓
              gameOver / victory
                    ↓
                mainMenu
```

### 7.2 函数命名
- `draw*`: 绘制函数

## 八、设计原则

1. **玩家优先**: 所有设计决策需回答"玩家感受到什么？"
2. **渐进式解锁**: 章节制解锁天赋，保持长期目标
3. **即时反馈**: 每次操作都有视觉/音频反馈
4. **平衡优先**: 数值需持续调整，避免Pay-to-Win
5. **移动优先**: 所有交互适配触摸操作
