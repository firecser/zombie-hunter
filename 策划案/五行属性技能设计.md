# 五行属性技能设计（属性树分支）

> 攻击性技能架构 = 基础（火力强化）+ 属性（五行：金木水火土）。
> 当前已实装 **火（爆炸弹）/ 水（干冰弹）/ 金（跃迁电子）** 三棵属性树。
> 每棵属性树自带「多重 / 疾速 / 暴击 / 穿透」**通用共享模板分支**（同名同结构，各自独立累加），再叠加本属性专属分支。
> 属性技能**独立 CD 释放**（初始较长、随技能等级与自身「疾速弹道」降低），**不受基础火力强化的射速影响**。

字段说明：
- **等级**：该分支在属性树总等级中解锁所需的最低档位（reqLevel）。
- **互斥**：同档二选一，一旦选了其中一个，另一个不再进入三选一池。
- **前置**：必须先点出所列分支（达到指定等级）才能出现。
- **上限**：该分支可单独升到的等级上限（maxLevel）。

## 三、金属性 · 跃迁电子 ⚡（参考《向僵尸开炮》跃迁电子）

金属性树围绕**弹射 / 导电 / 麻痹 / 电伤领域**展开。「导电」是金树的核心状态钩子，定义为 **冻结 / 减速 / 麻痹** 三种异常状态；金树自身的电磁脉冲(麻痹)即可自闭环触发超导，纯金流也能完整运转，无需依赖水树的减速/冻结。

### 设计要点（严谨性说明）

1. **雷霆一击的前置是「雷霆暴击」，不是裸名「暴击」**
   - 跃迁电子大类下**没有名为「暴击」的分支**；前置列引用的「雷霆暴击」是 Lv3 共享模板分支（内部 key：`crit`）。
   - `雷霆暴击` 只提供暴击率/暴击伤害加成，**不再**自带落雷；「暴击召唤落雷」的唯一来源是 `雷霆一击`（已修掉原本与雷霆暴击满级的重复）。

2. **静电场领域范围/时长随等级扩大**
   - 半径：基础 55px，每级 +12px → Lv1≈67px，Lv5≈115px。
   - 时长：基础 2600ms，每级 +200ms → Lv1≈2.8s，Lv5≈3.6s。
   - 生成概率固定 20%/级（Lv5 满级 100%）。

3. **同档互斥二选一**
   - Lv2：链式传导（多目标）↔ 高压电弧（高伤远程）。
   - Lv4：电磁脉冲（单体硬控，麻痹）↔ 静电场（群体电伤领域）。

4. **Lv5 质变分支前置明确**
   - 超导 → 需「链式传导」。
   - 雷霆一击 → 需「雷霆暴击」Lv1。

5. **数值平衡要点（v1.0.93 重平衡）**
   - **与火/水对称**：火(焚身)、水(冰爆)各有「对状态目标追加最大生命%伤害」的 Lv5 对称分支。金树原本超导只给弹射增伤、缺对等项 → 现超导重构为「对导电目标：弹射伤害 +20%/级、弹射次数 +1/级、**追加 2% 最大生命/级**」，与火/水形成三树对称。金超导最大生命系数(满级 10%)略低于火/水(满级 15%)，补偿是金的「导电」触发更广（麻痹/减速/冻结任一即可，且金自身电磁脉冲就能施加麻痹）。
   - **纯金流自闭环**：超导原触发条件为「冻结/减速」，来自水树，导致纯金流点出超导几乎无效。现导电统一含「麻痹」，金树 emp(电磁脉冲) 施加的麻痹即可触发超导 + 组合技(superconduct/conduct)，纯金流完整可玩。
   - **Lv5 双分支取舍清晰**：雷霆一击(暴击50%落雷=100%主伤害，maxLevel 1)定位「单体/Boss 爆发」，无视弹射衰减、打精英高效；超导定位「群体弹射增伤+追击」。两者赛道不同，组合投入越高回报越大。
   - **同档互斥对平衡**：Lv2 链式传导(多目标)↔ 高压电弧(高伤远程+距离)、Lv4 电磁脉冲(控制，喂超导/组合技)↔ 静电场(群体电伤 DPS)，各自取舍等价。
   - **三树横向定位**：火=暴力 AOE+灼烧链；水=控场+冰爆；金=链式弹射+电领域。专属分支每级增量均落在 20%~38% 区间，强度同量级。
   - **五行相生现状**：金生水（金+水持有 → 水伤 +15%）当前唯一可触发；金被「土」生（土属性树待实装），故金树相生加成暂缺，待土树补入后补齐五行闭环。
